# Security Policy

Please do not open a public issue for a security problem. Report it privately
through
[GitHub Security Advisories](https://github.com/dannyota/duolane/security/advisories/new).

Reports about credential handling, requests that reach the proxy from a browser
or another host, and anything that could expose a login or conversation are
especially welcome.

Never include real credentials, tokens, or conversation content in a report.
