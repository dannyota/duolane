# duolane Wiki

Use Claude and Codex models in one Claude Code session through a local proxy.
The model you request chooses the backend. Both providers keep their own
sign-ins.

- [Getting Started](Getting-Started.md): install, sign in, and send a request.
- [Connections](Connections.md): choose intercept or gateway mode.
- [CLI](CLI.md): commands, aliases, and Claude Code subagents.
- [Claude Accounts](Claude-Accounts.md): choose among several Claude logins.
- [Configuration](Configuration.md): ports, paths, and Codex transport.
- [Troubleshooting](Troubleshooting.md): recover from common startup and
  connection failures.

These pages are maintained in
[`docs/wiki/`](https://github.com/dannyota/duolane/tree/HEAD/docs/wiki) in the
source repository. See the [README](https://github.com/dannyota/duolane#readme)
for the quick start and the
[security design](https://github.com/dannyota/duolane/blob/HEAD/docs/design/security.md)
for trust boundaries.
